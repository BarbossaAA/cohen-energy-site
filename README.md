# cohen-energy.com | עמוד שיפוצים

עמוד יחיד שמודיע שהאתר בשיפוצים ויחזור בקרוב, לדומיין הראשי `cohen-energy.com`.

- קובץ יחיד: `index.html`, ללא build וללא תלויות חיצוניות פרט לגופן Heebo.
- `404.html` מחזיר כל כתובת אחרת לעמוד הבית, כי כל האתר בשיפוצים.
- `assets/og.jpg` הוא התמונה שמופיעה בשיתוף בוואטסאפ ובפייסבוק.

## סרגל הניווט

הסרגל מציג את מפת האתר העתידית: שירותים, חנות, מידע מקצועי וגלריה.
**כל הקישורים מצביעים ל־`/`**, כלומר כל לחיצה מחזירה לעמוד הבית ואין גישה
אמיתית לעמודי המשנה. בתחתית כל תפריט נפתח כתוב "נפתח עם עליית האתר החדש",
כדי שהמבקר יבין שאלו קטגוריות עתידיות ולא קישורים שבורים.

- מעל 980px: תפריטים נפתחים בריחוף ובפוקוס מקלדת, ב-CSS בלבד.
- מתחת ל-980px: כפתור המבורגר פותח תפריט מסך מלא אטום, עם כל הקטגוריות
  ותתי הקטגוריות פרושות יחד. בלי JavaScript הניווט פשוט מוצג פתוח.

להוספה או שינוי של קטגוריה: לערוך את `<nav class="nav">` ב-`index.html`.

## מה חי בעמוד

מאחורי הכל יש `assets/hero-field.jpg`: נוף בשעת זהב עם שמיים פתוחים,
גבעות פורחות, עצי זית ושדה פאנלים בקדמת התמונה.
התמונה נוצרה ב-Seedance 2.0 מתוך תמונת ה-hero האמיתית של אתרי
ההצעות, כדי לנקות את הרקע החקלאי ולהשאיר קומפוזיציה נקייה.
היא אינה צילום, ולכן אין להציג אותה כתיעוד של התקנה מסוימת.
היא מטושטשת, מוכהה ונעה לאט מאוד, כדי לשמש עומק רחוק ולא תחרות
על תשומת הלב. שאר הרקע מצויר ב-canvas מעליה, בלי וידאו:

- שדה פאנלים מצויר בפרספקטיבה מעל התמונה, שמגיב לתנועת העכבר
  וממשיך לנוע לבד כשאין תנועה.
- לחיצה במקום ריק שולחת אדוות אור על הפאנלים. גם לחיצה על סמל השמש.
- חלקיקי אור זהובים שעולים כלפי מעלה.

הרצועה "השמש עכשיו" מחשבת בזמן אמת את גובה השמש מעל ישראל:

- שעות הזריחה והשקיעה מחושבות ליום הנוכחי באזור הזמן `Asia/Jerusalem`, כך שהן נכונות גם למבקר מחוץ לארץ.
- ההספק והאנרגיה הם הדמיה למערכת ביתית של 22.61kWp (34 פאנלים של 665W), ולא נתוני אמת ממערכת מותקנת. זה כתוב במפורש בעמוד.
- אחרי השקיעה העמוד מחליף מצב לגוון קר ומראה מתי הזריחה הבאה.
- זוהר השמש ברקע נע לפי השעה האמיתית, כך שהעמוד נראה אחרת בבוקר, בצהריים ובלילה.

לעריכת פרטי קשר: החיפוש `972548373494` ו-`054-8373494` בקובץ `index.html`.
גודל המערכת להדמיה נמצא במשתנה `SYSTEM_KWP`.

## פלטה

כחול לילה וזהב, זהה למותג באתרי ההצעות. כל הצבעים מוגדרים כמשתני CSS
בראש ה-`<style>`: `--navy-*`, `--gold`, `--sun` ו-`--ice`.

## הרצה מקומית

```bash
py -3 -m http.server 8199
```

ואז לפתוח `http://localhost:8199`.

## DNS

הדומיין הראשי `cohen-energy.com` מתארח ב-GitHub Pages מהריפו הזה, עם `CNAME`.
בניגוד לתת-דומיינים, דומיין ראשי לא יכול להצביע ב-CNAME ודורש רשומות A ו-AAAA
אל שרתי GitHub. הרשומות המדויקות נמצאות בהודעת הפריסה שליוותה את הריפו הזה.

## נגישות וביצועים

- תמיכה מלאה ב-`prefers-reduced-motion`: התנועה נעצרת והרקע מצויר פריים אחד סטטי.
- ההנפשה של הכניסה מסתיימת אחרי 2.6 שניות בכל מקרה, כדי שתקלה בהנפשה לא תשאיר תוכן מוסתר.
- ה-canvas עוצר לגמרי כשהלשונית ברקע, ומצייר פחות תאים במסכים קטנים.
- העמוד עובד גם בלי JavaScript: ההודעה, הניווט, פרטי הקשר והקישורים סטטיים ב-HTML.
